ModaTv 手机端 v1.0.1。

播放器手势与面板重做（大屏全屏、详情页小屏同一套）：
双击画面 = 播放/暂停（原来的双击左右半屏快退快进取消，精确跳转用横滑预览后松手 seek）；
暂停后画面中央常驻一颗播放键，点它继续播；单击仍是显隐控制层，纵滑仍是左半屏亮度 / 右半屏音量。

锁定态重做：解锁入口固定到画面右侧竖排（居中偏上那颗 44dp 圆钮），点屏幕才出现、2.5 秒自收；
锁定期间暂停的中央播放键照常出现，锁定态也能双击播放/暂停。
画面右侧的截图按钮与相关回执一并移除（该位置让给解锁键）。

选集改成贴右的卡片列表：一列竖排、每张带 16:9 缩略图与集号，角标沿用预告 / VIP / 已看完，
当前集描边高亮；面板展开时压暗底层控制层，不再和底栏抢触摸。

换集、下一集、连播改为原地换流：旧画面留着、只叠一层"切换中"，新地址到手就地换源。
以前会先退回 Loading 把播放页整页卸掉，横屏状态跟着被还原，用户看到的是竖屏闪一下再横屏。

详情页选一集改为在本页换片源并自动开播，不再跳播放页路由——
点的是这一页的选集，就不该落进另一个页面、返回时把全屏状态也丢掉。
详情页小屏同时支持切清晰度：档位表取自实际在播那一集的 episodeInfo，切档 = 换地址，
面板与大屏共用同一个 QualitySheet。

弹幕快捷开关只写本剧覆盖，不再改写设置里的全局默认值。

自更新仍只认本仓库的 version-mobile.json 与 ModaMobile<版本>.apk，不与 TV 端共用发布资产。
