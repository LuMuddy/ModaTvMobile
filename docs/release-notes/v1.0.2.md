ModaTv 手机端 v1.0.2。

界面默认竖屏。整套布局本来就是按竖屏单列排的——首页 3 列海报、底栏三项、设置单列——
平板横过来只会把每一行拉宽：详情页 16:9 头图能到 720dp，底栏三项也摊在一米宽里。
现在清单直接锁 portrait；播放页与详情页全屏仍是唯一的例外，由运行时切横屏、退出时切回竖屏。
以前退出还回的是「跟随传感器」，平板上会自己转回横屏，和页面上的竖屏布局对不上。

平板上沿用与手机同一套布局：首页仍是 3 列、搜索仍是 2 列，不按屏宽改列数，
卡片随屏宽等比放大，两端看到的是同一个界面。

宽屏上仍然限宽的只有三处浮层：授权门的内容列 480dp（竖屏平板上「刷新二维码」不再拉成一条）、
自绘弹窗 420dp、播放器底部面板 840dp（播放页是唯一会横过来的页面）。
